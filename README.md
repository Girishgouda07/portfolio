# Girishgouda C S - Full Stack Developer Portfolio

A modern, responsive portfolio website showcasing my skills, experience, and projects as a Full Stack Developer.

## 🚀 Live Demo

[View Live Portfolio](https://your-vercel-link.vercel.app)

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **UI Components:** shadcn/ui, Radix UI
- **Icons:** Lucide React
- **Deployment:** Vercel
- **Analytics:** Google Analytics

## ✨ Features

- Responsive Design
- Dark Theme UI
- Smooth Animations
- Interactive Elements
- Contact Form with EmailJS
- Resume Download Option

## 📱 Sections

- Hero Section
- Skills Section
- Experience Section
- Projects Section
- Contact Section
